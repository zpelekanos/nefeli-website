NEFELI HADJIPITTA — STATIC WEBSITE
==================================

ΠΕΡΙΕΧΟΜΕΝΑ
- index.html                  Αρχική
- about.html                  Ποια είμαι
- approach.html               Θεραπευτική προσέγγιση
- services.html               Υπηρεσίες
- therapy.html                Σχετικά με τη θεραπεία
- space.html                  Ο χώρος μου
- contact.html                Επικοινωνία
- assets/styles.css           Κοινό styling
- assets/main.js              Mobile menu, FAQ, demo form

WINDOWS — LOCALHOST
1. Κάνε unzip τον φάκελο.
2. Κάνε διπλό κλικ στο start_localhost.bat.
3. Άνοιξε http://localhost:8000 αν δεν ανοίξει αυτόματα.
4. Για να κλείσεις τον server πάτησε Ctrl+C στο μαύρο παράθυρο.

ΕΝΑΛΛΑΚΤΙΚΑ
Άνοιξε Command Prompt μέσα στον φάκελο και γράψε:
    py -m http.server 8000
ή:
    python -m http.server 8000

Μετά άνοιξε:
    http://localhost:8000

ΣΗΜΑΝΤΙΚΟ
- Το website είναι static και η πλοήγηση μεταξύ όλων των σελίδων λειτουργεί κανονικά.
- Η φόρμα επικοινωνίας είναι UI/demo και δεν στέλνει email μέχρι να συνδεθεί με backend ή form service.
- Τα Google Fonts και η φωτογραφία της αρχικής φορτώνονται από το internet, όπως στο αρχικό HTML.
- Τα πραγματικά στοιχεία βιογραφικού, διεύθυνσης, email, τηλεφώνου και φωτογραφιών χώρου δεν υπήρχαν στο αρχικό αρχείο και έχουν μείνει ως ασφαλή placeholders.
