NEFELI WEBSITE — SETUP GITHUB + PAGES CMS + NETLIFY
===================================================

ΤΙ ΕΧΕΙ Η ΕΚΔΟΣΗ ΑΥΤΗ
----------------------
Το design/HTML/CSS παραμένει κλειδωμένο.
Τα κείμενα και οι επιλεγμένες εικόνες βρίσκονται στον φάκελο content/ και μπορούν να αλλάζουν από GUI μέσω Pages CMS.
Η Νεφέλη δεν χρειάζεται να ανοίγει HTML ή CSS.

ΣΗΜΑΝΤΙΚΟ
---------
Στο GitHub repository root πρέπει να φαίνονται άμεσα:
- index.html
- .pages.yml
- netlify.toml
- assets/
- content/

ΜΗΝ ανεβάσεις τον εξωτερικό φάκελο σαν επιπλέον επίπεδο, γιατί τότε το .pages.yml και το index.html δεν θα είναι στο root.

1. CREATE GITHUB REPOSITORY
---------------------------
1) Πήγαινε στο https://github.com και κάνε login.
2) Πάτησε + επάνω δεξιά > New repository.
3) Repository name: π.χ. nefeli-website
4) Μπορεί να είναι Private.
5) Create repository.
6) Στο repository πάτησε Add file > Upload files.
7) Κάνε unzip το ZIP που σου έδωσα.
8) Άνοιξε τον φάκελο και σύρε στο GitHub ΟΛΑ ΤΑ ΠΕΡΙΕΧΟΜΕΝΑ του φακέλου, όχι τον ίδιο τον εξωτερικό φάκελο.
9) Επιβεβαίωσε ότι ανέβηκε και το αρχείο .pages.yml.
10) Commit changes.

2. CONNECT PAGES CMS
--------------------
1) Πήγαινε στο https://app.pagescms.org
2) Sign in with GitHub.
3) Εγκατάστησε/ενέκρινε το Pages CMS GitHub App για το repository nefeli-website.
4) Άνοιξε το repository μέσα από το Pages CMS.
5) Δεν χρειάζεται να δημιουργήσεις .pages.yml — είναι ήδη έτοιμο μέσα στο ZIP.
6) Θα εμφανιστούν στο αριστερό menu:
   - Γενικά στοιχεία
   - Αρχική σελίδα
   - Ποια είμαι
   - Θεραπευτική προσέγγιση
   - Υπηρεσίες
   - Σχετικά με τη θεραπεία
   - Ο χώρος μου
   - Επικοινωνία
7) Κάνε δοκιμή αλλάζοντας ένα μικρό κείμενο και πάτησε Save.

3. ΔΩΣΕ ΠΡΟΣΒΑΣΗ ΣΤΗ ΝΕΦΕΛΗ ΧΩΡΙΣ ΝΑ ΕΙΝΑΙ DEVELOPER
------------------------------------------------------
Η πιο απλή επιλογή είναι collaborator του Pages CMS.
1) Μέσα στο Pages CMS άνοιξε τη διαχείριση Collaborators για το repository.
2) Κάνε invite το email της Νεφέλης.
3) Η Νεφέλη μπορεί να επεξεργάζεται content και media χωρίς να χρειάζεται να μάθει Git/GitHub.
4) Δεν της δίνεις πρόσβαση σε HTML/CSS από το CMS configuration που έχει ετοιμαστεί.

4. DEPLOY ΣΤΟ NETLIFY
---------------------
1) Πήγαινε στο https://app.netlify.com και κάνε login.
2) Add new project > Import an existing project.
3) Διάλεξε GitHub.
4) Επίλεξε το repository nefeli-website.
5) Το project είναι απλό static site και περιέχει netlify.toml.
6) Build command: δεν χρειάζεται.
7) Publish directory: .
8) Πάτησε Publish / Deploy.
9) Το Netlify θα σου δώσει προσωρινό URL τύπου something.netlify.app.

Από εδώ και πέρα, όταν η Νεφέλη κάνει Save στο Pages CMS:
Pages CMS -> ενημερώνει το GitHub -> το Netlify βλέπει την αλλαγή -> κάνει νέο deploy αυτόματα.

5. ΔΟΚΙΜΗ ΤΟΥ CMS
-----------------
Μετά το πρώτο deploy:
1) Pages CMS > Αρχική σελίδα.
2) Άλλαξε π.χ. τον Υπότιτλο.
3) Save.
4) Περίμενε να ολοκληρωθεί το νέο Netlify deploy.
5) Κάνε refresh το website.

6. ΑΛΛΑΓΗ HERO ΕΙΚΟΝΑΣ
----------------------
Pages CMS > Αρχική σελίδα > Hero > Hero εικόνα.
- Αν το πεδίο μείνει κενό, το site κρατά την υπάρχουσα hero εικόνα του design.
- Αν ανεβάσει νέα εικόνα, αυτή αποθηκεύεται στο assets/uploads/ και χρησιμοποιείται στο website.

7. ΦΩΤΟΓΡΑΦΙΕΣ 'Ο ΧΩΡΟΣ ΜΟΥ'
----------------------------
Pages CMS > Ο χώρος μου > Gallery > Φωτογραφίες.
Υπάρχουν 5 θέσεις. Σε κάθε θέση μπορεί να αλλάξει:
- Λεζάντα
- Εικόνα
Το layout παραμένει κλειδωμένο.

8. CUSTOM DOMAIN (ΑΡΓΟΤΕΡΑ)
---------------------------
Όταν είσαι έτοιμος, στο Netlify μπορείς να προσθέσεις το δικό της domain από Domain management.
Δεν χρειάζεται για να δοκιμαστεί το site και το CMS.

9. ΠΡΟΣΟΧΗ ΣΤΗ ΦΟΡΜΑ ΕΠΙΚΟΙΝΩΝΙΑΣ
---------------------------------
Η υπάρχουσα φόρμα είναι ακόμη demo UI. Δεν στέλνει πραγματικό email.
Για πραγματική αποστολή θα χρειαστεί να συνδεθεί αργότερα με Netlify Forms ή άλλο email/backend service.

10. BACKUP / ΑΣΦΑΛΕΙΑ
---------------------
Κάθε αλλαγή που γίνεται από το Pages CMS γράφεται στο GitHub, άρα υπάρχει ιστορικό αλλαγών και μπορείς να επαναφέρεις προηγούμενη έκδοση αν χρειαστεί.
