ΟΔΗΓΟΣ ΝΕΦΕΛΗΣ — ΠΩΣ ΑΛΛΑΖΩ ΤΟ WEBSITE
========================================

Δεν χρειάζεται να ανοίξεις κώδικα.

1) Άνοιξε το Pages CMS από το link που θα σου δοθεί / https://app.pagescms.org
2) Μπες στο website repository που έχεις προσκληθεί.
3) Από το αριστερό menu διάλεξε τη σελίδα που θέλεις:
   - Αρχική σελίδα
   - Ποια είμαι
   - Θεραπευτική προσέγγιση
   - Υπηρεσίες
   - Σχετικά με τη θεραπεία
   - Ο χώρος μου
   - Επικοινωνία
4) Άλλαξε το κείμενο στο αντίστοιχο πεδίο.
5) Για φωτογραφία, πάτησε στο πεδίο εικόνας και επίλεξε/ανέβασε νέα φωτογραφία.
6) Πάτησε Save.
7) Μετά το Save το website ενημερώνεται μέσω του deployment.

ΤΙ ΜΠΟΡΕΙΣ ΝΑ ΑΛΛΑΞΕΙΣ
-----------------------
- Τίτλους και υποτίτλους
- Παραγράφους
- Κείμενα καρτών/υπηρεσιών
- Συχνές ερωτήσεις και απαντήσεις
- Στοιχεία επικοινωνίας
- Hero φωτογραφία
- Φωτογραφίες του χώρου
- Λεζάντες φωτογραφιών

ΤΙ ΔΕΝ ΧΡΕΙΑΖΕΤΑΙ ΝΑ ΑΓΓΙΖΕΙΣ
------------------------------
- HTML
- CSS
- fonts
- responsive/mobile layout
- menu structure
- code

Έτσι το design μένει σταθερό ενώ το περιεχόμενο μπορεί να αλλάζει εύκολα.
